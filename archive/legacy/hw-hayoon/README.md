# HW 하윤 · 운송 파트너

AI-Bootcamp의 하윤 운송 파트너 초안을 고도화한 **JavaScript 앱 프로토타입**입니다. 별도 npm 패키지를 설치하지 않고 실행할 수 있습니다.

## 실행

Node.js 22 이상에서 이 폴더를 열고 실행합니다.

```sh
npm run dev
```

브라우저 주소: **http://localhost:5173**

다른 포트가 필요하면 `npm run dev -- --port 5174`를 사용합니다. ES modules와 로컬 지도 데이터를 불러오므로 HTML 파일을 직접 여는 대신 로컬 서버를 사용해 주세요.

## 체험할 수 있는 내용

- **콜 찾기**: 구미 기반 콜 11건, 내 차량 5톤 맞춤, 품목·지역 검색, 유형·최소 운임·공차거리 필터, 운임·거리·효율 정렬.
- **콜 비교**: 목록의 `비교` 또는 상세의 `이 콜 비교에 담기`로 최대 3건 선택. 공차 포함 거리·km당 운임·주행비 차감 참고액을 비교하고 선택을 비울 수 있습니다. 설정과 선택은 새로고침 뒤에도 유지됩니다.
- **자원 운송 정보**: 재질·프로젝트 등급·등록/실측 중량·마대 수와 판매 공장·인수 업체를 연결합니다. 없는 공정·오염도 정보는 미등록으로 표시합니다.
- **수락 전 확인**: 차량 적재량, 등록 상차 지원, 별도 확인이 필요한 운반 허가를 나눠 보여줍니다.
- **지도**: 저장소의 실제 도로 선형과 로컬 OpenStreetMap 타일. 콜 선택·상세·확대·차고지 보기.
- **저장한 콜**: 즐겨찾기와 새로고침 후 복원.
- **내 운송**: 조건·확정 운임 확인 → 수락 → 상차지 도착 → 모든 마대의 수거 무게 → 운송 → 하차지 도착 → 구매자 검사 대기.
- **정산**: 지급 예정·지급 완료·검사 대기 구분, 주간 운임, 상태 필터, CSV 내려받기.
- **내 정보**: 차량·허가 코드 예시, 운행 상태·맞춤 필터 설정, 시연 데이터 초기화.
- **보조 흐름**: 알림, 운송 가이드, 인계용 정보 복사, 배차 해제.
- **운송 기록**: 내 운송의 `운송 기록`, 최근 운송의 `인계 정보`에서 실제 조작 시각과 상태를 보고 참고용 JSON을 내려받습니다. 이전 기록에 없는 시각은 만들지 않습니다.
- **오프라인**: 연결이 끊기면 위에 안내가 나옵니다. 저장된 화면 보기·비교·저장은 그대로 되고, 서버로 보내야 하는 수락·마대 중량·도착 확인 전송은 이유와 함께 막습니다(`src/domain.js`의 `assertConnected`, 실제 API를 붙일 지점). 입력한 운임·중량은 지워지지 않습니다.

앱 메뉴에서 **콜 찾기 → 상세 보기 → 운송 조건 확인하고 수락**을 누르면 전체 흐름을 체험할 수 있습니다. 상차 확인 화면은 선택한 콜의 실제 예시 마대 수만큼 입력칸을 만듭니다.

비교를 체험하려면 콜 카드에서 **비교**를 2~3건 선택한 뒤 목록 상단의 **콜 비교**를 누릅니다. 주행비 가정은 0~10,000원/km의 정수로 조절할 수 있습니다. 기본 450원/km는 시연 가정이며, 운임 상한에서 주행비만 뺀 값은 실제 수익이나 확정 운임이 아닙니다. 수락한 콜은 비교 대상에서 빠지고 진행·완료한 콜을 다시 담을 수 없습니다.

## 디자인과 정보 구성

- 메뉴는 콜 찾기·내 운송·정산 관리·저장한 콜·내 정보 5개입니다. 모바일은 하단 메뉴 5칸, 태블릿·데스크톱은 사이드바에 같은 5개가 있습니다.
- 콜 찾기 첫 화면은 375×667부터 1440px까지 첫 콜의 경로·운임·중량·상세 보기 버튼이 스크롤 없이 보이게 했습니다. 요약 수치는 모바일·태블릿에서 한 줄로 줄이고, 키 작은 휴대폰에서는 숨깁니다(정산 관리·내 운송에서 확인).
- 보조 글자는 12px 이상, 흰 배경 대비 4.5:1 이상으로 맞췄습니다(`readability.css`, 마지막에 불러옴). 중량은 운임·경로와 함께 굵고 크게 표시합니다.
- 원본 A안의 지도 맥락, B안의 비교 목록, C안의 큰 다음 행동을 하나의 앱으로 결합했습니다.
- 운임·공차·적재거리·상차 시간·적재량을 같은 위치에서 비교하도록 정리했습니다.
- 데스크톱은 목록/지도 분할, 모바일은 하단 탐색과 목록/지도 전환을 제공합니다.
- 브랜드명 **HW 하윤**은 사용자 요청을 반영했습니다. 원본 서비스의 자원순환·운송 맥락과 녹색 계열을 유지했습니다.
- 세부 기준은 저장소 루트 [DESIGN.md](../DESIGN.md), 소스 확인 내용은 [SOURCE_REVIEW.md](./docs/SOURCE_REVIEW.md)에 있습니다.
- 해외 원료 거래·재사용·소재 여권·화물 서비스의 정보 구조를 참고했습니다. 공식 출처와 적용 판단은 [글로벌 사례·UX 분석](./docs/GLOBAL_REFERENCES.md), 같은 범위를 재현·개선할 개발 지시는 [구현 프롬프트](./docs/UX_IMPLEMENTATION_PROMPT.md)에 있습니다.

## 기술 구성

HTML, CSS, JavaScript ES modules, Node.js 내장 정적 서버·테스트만 사용합니다. 지도 라이브러리 Leaflet과 글꼴·타일은 원본 저장소에서 재사용했습니다. TypeScript·추가 런타임 패키지·외부 CDN은 사용하지 않습니다.

주요 파일:

| 파일 | 역할 |
|---|---|
| `app.js` | 앱 상태·이벤트·대화상자·브라우저 저장 |
| `src/views.js` | 화면·콜 카드·상세·운송·정산 구성 |
| `styles.css` | 디자인 토큰·컴포넌트·반응형 스타일 |
| `src/data.js` | 출처를 보존한 예시 콜과 정산 데이터 |
| `src/domain.js` | 검색·정렬·수락 조건·운송 단계·저장값 검증 |
| `src/insights.js` | 비교 선택·주행비 계산·조건 확인·운송 기록 생성 |
| `src/reference-views.js`, `reference.css` | 비교·자원 정보·조건·기록 UI |
| `src/format.js` | 금액·HTML 이스케이프·한국 기준 날짜 |
| `src/map.js`, `src/routes.json` | 오프라인 지도·원본 도로 경로 |
| `server.mjs` | 로컬 전용 서버 |

## 검증

```sh
npm run check
```

JavaScript 구문 검사, Node 내장 도메인 테스트, `dist/` 정적 빌드를 순서대로 실행합니다. `lint`는 구문 및 JavaScript 전용 파일 검사이며 별도 ESLint 실행을 의미하지 않습니다. 정적 빌드 결과를 일반적인 정적 호스팅에 사용할 수 있으며, 현재 작업에서는 외부 배포하지 않았습니다.

실제 브라우저 검증은 로컬 서버 실행 후 `npm run test:browser`로 재현합니다. macOS에 설치된 Google Chrome을 격리된 임시 프로필로 실행하며 추가 패키지는 필요 없습니다. 1440/768/390/375px에서 5개 메뉴, 첫 콜의 경로·운임·중량·버튼 노출, 5개 화면의 글자 크기·대비, 오프라인 차단과 재연결 뒤 수락, 새 비교·자원 정보·운송 기록 대화상자를 확인합니다(2026-11-05 기준 159개 통과). 선택 한도·비용 경계·포커스 복귀·저장 호환·기록 JSON과 기존 운송 흐름을 검사하며, 최신 실행 결과는 [BROWSER_TEST_RESULTS.json](./docs/BROWSER_TEST_RESULTS.json)에 있습니다.

## 범위와 데이터

이 버전은 **실제 서버에 연결하지 않은 로컬 시연 앱**입니다. 배차·결제·지급·인증·올바로 제출은 발생하지 않습니다. 브라우저의 localStorage에 예시 상태만 저장합니다. 내 정보의 초기화로 되돌릴 수 있습니다.

운송기사의 도착 확인과 구매자의 검사를 구분합니다. 운송기사가 도착을 보냈다고 정산 완료로 바꾸지 않습니다. 5톤 초과 수락, 운임 상한 초과, 동시 중복 배차, 마대 확인 누락을 차단합니다. 수거 무게의 차이가 5%를 넘으면 안내하며, 실제 분쟁 판단은 이 프로토타입에서 수행하지 않습니다.

지도·거리·시간에는 실시간 교통이나 회전 제한이 반영되지 않습니다. 내 위치는 GPS가 아닌 구미 시연 차고지입니다. 지역 밖 확대는 내장 저해상도 타일을 사용합니다. 일반적인 인터넷 연결 없이도 앱과 지도를 확인할 수 있습니다.

예시 업체·좌표·운임은 실제 거래 조건이나 검증된 주소가 아닙니다. 외부 공유 제한이 있는 20,580개 공장 좌표 원본은 복사하지 않았습니다. 지도·글꼴·라이브러리 출처와 라이선스는 [THIRD_PARTY_NOTICES.md](./THIRD_PARTY_NOTICES.md)에 있습니다.
