# 그물마중

제4회 대한민국 대학창업대전 로컬 혁신 창업 해커톤 작업 자료입니다.

중심 아이템은 섬에서 분리한 폐어망을 싣기 전에 육상 재활용업체와 인수 조건을 맞춰 주는 서비스입니다. 첫 실증지는 보령 삽시도입니다. 자세한 내용은 [보령 삽시도 폐어망 재활용 사업화 및 실증안](보령%20삽시도%20폐어망%20재활용%20사업화%20및%20실증안.md)에 있습니다.

## 들어 있는 것

| 위치 | 내용 |
|---|---|
| `보령 삽시도 폐어망 재활용 사업화 및 실증안.md` | 폐어망 인수 조건 연결 서비스 사업화와 실증안 |
| `나주 혁신도시 금요일 점심 사업화 및 실증안.md` | 함께 검토한 다른 후보 아이템 |
| `reports/` | 후보별 시장성과 수익모델 보고서 |
| `research_notes/` | 보고서를 쓰며 모은 조사 메모와 출처 |
| `crawl_local_problems.py` | 로컬실록지리지 문제발굴 글을 내려받는 스크립트 |
| `로컬비즈니스유형_개요.csv`, `로컬비즈니스유형_사례DB.csv` | 로컬 비즈니스 유형과 국내외 사례 100건 |
| `로컬실록지리지_유형별_지역요약.csv`, `반복문제_심각지역.csv` | 지역별 글 수 집계 |
| `로컬창업_아이디어50.csv` | 창업 아이디어 50개와 근거 |

## 공개본에서 뺀 것

- **로컬실록지리지 원본 글과 그 글로 만든 표:** 작성자, 구성원, 팀명, 주소 칸이 있거나 다른 사람이 쓴 글 원문이 그대로 들어 있습니다. 집계표만 남겼습니다. 원본은 `python crawl_local_problems.py`로 다시 받을 수 있습니다.
- **주최 측 자료:** 사전교육 강의 자료, 참가자 OT 자료, 운영계획(안), 사업계획 작성 템플릿, 안내 이미지
- **작업 도구가 남긴 상태 파일**
