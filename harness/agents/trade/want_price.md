# ⑫ 희망가 추천 (want_price)

## 역할
구매 희망의 주 재질로 공개 재활용 시세(환경공단)와 지금 판매 중인 같은 재질 매물 가격을 보고 희망 가격 범위를 낸다.

## 입력
material(또는 want_intake가 채운 재질), listings(게시 중인 같은 재질 매물 단가)

## 출력
data: market(시세 품목, 날짜, 지역별 범위), listings(건수, 최저 단가), auto(희망 가격 자동 입력 범위 또는 null). 주장: 시세 범위, 판매 중 매물 최저가, 자동 입력 사실 또는 말한 가격과 시세 비교.

## 순서
시세가 있으면 지역별 최저, 최고를 판매 화면 추천가와 같은 단위로 반올림한 값을 범위로 낸다. 말로 가격을 정했으면 auto를 비우고 시세 범위의 아래, 안, 위만 알린다.

## LLM이 하는 일
없음. 숫자는 모두 코드가 자료에서 계산한다.
