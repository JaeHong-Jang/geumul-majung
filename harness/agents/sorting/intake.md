# ⑨ 말 입력 정리 (intake)

## 역할
마대 등록 화면에서 사용자가 말한 글(서버 로컬 Whisper가 음성을 바꾼 글)을 등록 칸으로 나눈다. 품목, 주 재질, 무게, 수거 가능일, 수거 안내, 메모.

## 입력
transcript(말한 글), today(KST 날짜)

## 출력
data: fields(채운 칸), sources(칸마다 rule 또는 llm), dropped(검산에서 버린 칸), llm(ok, failed, off), hazard. 주장: 칸마다 한 줄, 다른 재질 언급, 위험어 언급, 버린 값 수, 개인정보 제외.

## 도구
calc.alias_map(재질 별칭), harness.yaml의 waste_keywords, material_codes, code_materials(팀 가정). 날짜는 코드가 오늘 기준으로 계산한다(내일, 모레, 다음 주 화요일, 12월 3일).

## LLM이 하는 일
규칙이 비워 둔 칸만 채운다(스키마 JSON, 품목 코드는 목록 enum). 받은 값은 코드가 검산한다. 재질은 아는 재질이면서 글에 있어야 하고, 무게 숫자는 글에 있어야 하고, 품목 코드는 이름 낱말이 글에 있어야 하고, 수거 안내와 메모는 글에 있는 말 그대로이거나, 잘못 들린 낱말을 소리가 비슷한 낱말로 고친 것이어야 하며 무게, 날짜, 개인정보가 없어야 한다. 고친 낱말은 들은 말과 자모로 비교해 0.8 이상 비슷하거나 현장 낱말이면서 0.6 이상이어야 하고, 숫자와 숫자 음절은 고칠 수 없다. 아니면 버린다. 고쳐 채웠으면 사람이 들은 말과 비교하도록 주장으로 알린다.

## 하지 않는 일
마대를 만들거나 제출하지 않는다(사람이 확인 후 제출). 말한 글 원문을 data에 넣지 않는다(agent_runs에 저장되므로). 섞인 재질의 무게를 짐작하지 않는다.
