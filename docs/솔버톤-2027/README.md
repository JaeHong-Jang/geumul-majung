# 그물마중 · 2027 지역 창업 솔버톤

충남 보령시 삽시도에서 폐어망을 반출하기 전에 지정 재활용업체의 인수 조건을 비교하고, 육상에서 실제로 인수한 중량을 기준으로 처리비와 운영료를 정산하는 시제품이다.

두 화면은 동일한 가상 반출 건을 시연한 결과다. 5톤 중 4톤 인수를 가정하면 고객의 기존 지출은 150만 원, 새 지출은 138만 원이다. 운영료 매출 16만 원에서 건별 직접비 11만 원을 빼면 팀 공헌이익은 5만 원이다.
