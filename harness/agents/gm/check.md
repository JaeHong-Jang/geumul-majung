# 반출 법 점검 (gm_check)

**하는 일**: 반출 한 건을 보고 집하장 담당자와 운영자가 확인할 목록을 만든다.

**법 항목**(근거 조문 id 필수, `data/law_articles.json`)
- 생활폐기물과 사업장폐기물 구분(wma-2), 운반자 신고·허가(wma-rule-66-6-11, wma-46, wma-25), 전자인계서 대상(wma-18-3), 집하장 관리대장(fa-79), 통발·자망 보증금(fa-81)

**현장 항목**(기록 값과 계산에서만)
- 로프 분리 여부와 두 조건의 예상 인수량·고객 절감 차이(gm.rules.calculate), 재질 미확인이면 표본 확인, 1톤 초과면 반입 신청 기한(출항 24시간 전, 팀 시제품 규칙)

**LLM**: 법 항목을 쉬운 말로 한 문장 요약(게이트를 통과할 때만). 법 판단은 하지 않는다.
