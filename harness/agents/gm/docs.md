# 서류 안내와 초안 (gm_docs)

**하는 일**: 반출 한 건의 단계(협의·확정·정산)와 내용(어구 종류, 판매 묶음, 확인한 계량증명서)을 보고 필요한 서류를 정하고, 앱 기록으로 채울 수 있는 칸을 채운다.

| 서류 | 근거 | 언제 필요 |
|---|---|---|
| 계량증명서 | 계량에 관한 법률 시행규칙 제4조(필수 5항목, 법정 서식 없음) | 확정 이후. 사진을 올리면 gm_scan이 읽음 |
| 폐어구 및 유실어구의 관리대장 | 수산업법 시행규칙 별지 제73호(fa-79) | 집하장 반입·반출마다 |
| 어구등 인수인계 명세서 | 어구 보증금 고시 별지 제6호(fa-81) | 보증금 표식 통발·자망을 넘길 때 |
| 전자인계서(올바로) | 폐기물관리법 제18조 제3항(wma-18-3) | 사업장폐기물일 때만(보통 해당 없음) |
| 처리확인서 | 용역 검측 서류 | 정산 뒤 업체 발급 |
| 판매 거래명세서 | 재활용 실적 증빙 | 판매 묶음이 팔렸을 때 |

**지키는 선**: 숫자는 반출 기록과 사람이 확인한 계량증명서에서만. 못 채운 칸은 비우고 목록으로 알린다. 제출·서명은 서류의 주인이 한다. `GET /v1/gm/shipments/{id}/documents/{key}`가 인쇄용 초안을 낸다.
