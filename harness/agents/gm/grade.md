# 판매 가능 판정 (gm_grade)

**하는 일**: 집하장에서 떼어 놓은 폐어구 묶음이 재활용업체가 돈을 주고 사 갈 원료인지 판정한다. 팔 수 없으면 왜 안 되는지, 조건부면 무엇을 하면 되는지, 누가 살 만한지(공개 자료의 업체, 대천항 기준 거리)를 낸다.

**판정 규칙**(KMI 2023 재활용업체 현장조사)
- 바다에서 건진 것(조업 중 인양, 침적, 해안) → 처리 대상(열 회수만)
- 섞여 있음 → 처리 대상, 종류별로 떼면 후보
- 잘린 그물, 재질 미확인 → 조건부(업체 확인)
- 자망의 뜸줄·발줄 → 떼면 나일론 비율 50%→80%
- 납 봉돌 → 떼어 금속으로 따로

**하지 않는 일**: 매입가를 짐작하지 않는다. 업체가 공개한 매입가가 없어 견적(매입 제안)으로만 받는다. LLM을 쓰지 않는다.
